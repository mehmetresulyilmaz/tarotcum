# 🔮 Mistik Kehanet: Ücretsiz Online Tarot Falı

![Tarot Banner](https://img.shields.io/badge/Tarot-Reading-7b2cbf?style=for-the-badge&logo=opsgenie&logoColor=white)
![Status](https://img.shields.io/badge/Durum-Yay%C4%B1nda-success?style=for-the-badge)
![Platform](https://img.shields.io/badge/Platform-Web-blue?style=for-the-badge)

**Mistik Kehanet**, kadim tarot destesini modern bir arayüzle buluşturan, kullanıcıların sezgilerine rehberlik eden interaktif bir web uygulamasıdır. 

🔗 **Canlı Önizleme:** [mehmetresulyilmaz.github.io/tarotcum](https://mehmetresulyilmaz.github.io/tarotcum/)

---

## ✨ Özellikler

* 🃏 **Görsel Kart Deneyimi:** Klasik Tarot destesi kartlarıyla etkileşimli seçim.
* 📜 **Anlık Yorumlama:** Seçilen kartın anlamı ve hayata dair mesajları anında görüntülenir.
* 🌙 **Minimalist & Mistik Tasarım:** Göz yormayan, odaklanmayı kolaylaştıran karanlık tema.
* 📱 **Tam Mobil Uyumluluk:** Responsive yapısı sayesinde telefon ve tabletlerde kusursuz deneyim.
* ⚡ **Hızlı ve Pratik:** Gereksiz karmaşadan uzak, direkt sonuca odaklı akış.
* 💾 **Geçmiş Kaydı:** Baktırdığınız falları yerel hafızada saklayabilir ve dilediğiniz zaman silebilirsiniz.

---

## 🛠️ Teknik Detaylar

Bu proje, performans ve sadelik ön planda tutularak geliştirilmiştir:

- **Frontend:** React 18, TypeScript
- **Tasarım:** Tailwind CSS (Modern ve Minimalist Stil)
- **Animasyonlar:** Framer Motion (Motion/React)
- **İkonlar:** Lucide React
- **Yayınlama:** GitHub Pages / Netlify

---

## 🚀 Kurulum ve Çalıştırma

Projeyi kendi yerelinizde çalıştırmak isterseniz:

1. Depoyu klonlayın:
   ```bash
   git clone https://github.com/mehmetresulyilmaz/tarotcum.git
   ```
2. Proje dizinine gidin:
   ```bash
   cd tarotcum
   ```
3. Bağımlılıkları yükleyin:
   ```bash
   npm install
   ```
4. Geliştirme sunucusunu başlatın:
   ```bash
   npm run dev
   ```
